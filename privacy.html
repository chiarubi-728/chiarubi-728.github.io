隱私權政策

更新日期：2026 年 10 月 23 日

適用範圍首頁與圖鑑PSN 與 Google 資料資料移除聯絡

1. 適用範圍與維護者

Rubi’s Cluttered Corner 是由 GitHub 使用者 chiarubi-728 維護的個人專案入口，包含卡蒂狗・風速狗圖鑑、PSN Game Catalog，以及尚未開放的 App 預留卡片。本政策說明這些已公開頁面如何處理資料，並在第 3 節完整說明 PSN Game Catalog 的 Google 登入與雲端同步。

各工具的資料處理依本頁對應章節及工具內提示進行。App 尚未提供入口；其功能與資料用途會在公開前另行說明。

2. 首頁與卡牌圖鑑

  • 通用首頁：提供公開介紹及專案連結，沒有登入、上傳表單或 Google 授權功能，也不讀取你的私人遊戲庫或 Drive。
  • 卡蒂狗・風速狗圖鑑：提供公開卡牌資料、圖片及頁面內搜尋、篩選和排序。目前沒有 Google 登入或 Drive 備份功能，瀏覽圖鑑不會啟動遊戲庫的 Google 同步。
  • 網站託管及圖片：頁面與圖片透過網路載入，GitHub Pages 及實際提供圖片的來源可能依其政策處理 IP 位址、瀏覽器資訊等連線資料。GitHub 的處理方式請參閱 GitHub 隱私權聲明。
  • 網站追蹤：通用首頁沒有加入分析工具、廣告追蹤或追蹤用 Cookie。

3. PSN Game Catalog：遊戲庫、Google 登入與雲端同步

此節適用於 PSN Game Catalog。其功能介紹見 應用程式介紹；既有的 遊戲庫專屬政策頁也繼續保留。

PSN Game Catalog 是由 GitHub 使用者 chiarubi-728 維護的個人 PlayStation 遊戲整理工具，合併 Sony 數位授權與 PSNProfiles 遊玩、獎盃紀錄，提供分類、標籤、筆記及選用的 Google Drive 自動同步。

遊戲庫先保存在你的瀏覽器。只有你連接 Google 並授權後，才會讀寫該 Google 帳號的 Drive 應用程式資料。網站不要求你提供 Google 或 PlayStation 密碼。

3.1 處理哪些資料，以及用途

  • 遊戲庫資料：匯入或同步的遊戲名稱、商品識別碼、平台、數位授權與 PS Plus 資訊、由你設定並確認的 PSN 帳號、Sony 數位庫帳號確認時間及遊玩、獎盃進度；來源有提供時也包含取得／領取及最後獲得獎盃日期，用於合併、搜尋、排序、顯示及整理遊戲，不讀取付款紀錄。
  • 個人整理：你設定的分類、標籤、筆記、名稱別名、標記、手動遊玩／獎盃配對、保持分開設定及配對前後的紀錄識別關係，用於保存你的整理結果及繼承分類與筆記。
  • Google 帳號資料：授權後讀取帳號識別碼（sub）及電子郵件。識別碼用於辨識同步帳號，電子郵件用於顯示目前連接的帳號。
  • 同步資訊：瀏覽器保存 OAuth Client ID、Google 帳號識別碼、同步版本摘要及時間，用於比較版本及避免把不同帳號的資料直接覆蓋。

舊版本曾保存的最後遊玩日期仍可隨既有備份保留與還原；現行版本不再主動查詢或顯示這項日期。

3.2 Google 授權範圍

  • openid：辨識你登入的 Google 帳號。
  • https://www.googleapis.com/auth/userinfo.email：顯示連接的帳號電子郵件。
  • https://www.googleapis.com/auth/drive.appdata：在你自己的 Google Drive 應用程式資料夾（appDataFolder）中讀寫遊戲庫備份。

Drive 權限限於本應用程式的隱藏資料空間，不能據此瀏覽或修改你的其他 Drive 文件。不同 Google 帳號的雲端資料分開儲存。

3.3 資料存在哪裡

遊戲庫、同步設定與復原副本保存在目前瀏覽器的網站儲存空間（localStorage）。Google 電子郵件及存取權杖只保留在目前頁面的記憶體；權杖不寫入網站儲存空間、匯出備份或 Git 儲存庫。

來源同步時，整合腳本會使用 Tampermonkey 的本機暫存空間，保存本輪的 PSN 帳號、回傳目的與期限，並在來源分頁與本遊戲庫之間傳送 Sony 數位授權或 PSNProfiles 公開遊玩與獎盃紀錄。這讓 Sony 登入跳轉後仍可帶入已填帳號，並在儲存後接續下一步。多個來源任務無法唯一對應時，不會任意選擇帳號。密碼、Cookie 與存取權杖不進入這個暫存。Sony 暫存有效期限最多 15 分鐘，PSNProfiles 最多 20 分鐘；資料在接收、完成、取消或逾時後清除，若瀏覽器非正常關閉，過期暫存會在下次開啟網站時清除。移除整合腳本及其資料也能清除這些暫存。

Sony 來源分頁也會透過 Tampermonkey 的分頁暫存及該分頁的 sessionStorage 保存隨機同步識別與管理頁來源，供登入跳轉後找回同一輪任務。這份分頁識別不含帳號密碼、Cookie 或存取權杖，且只有原本尚未取消、未過期的任務能繼續使用。正常完成或接續獎盃步驟時清除；取消後的識別立即失效，在來源頁再次檢查、到期或關閉分頁時清除。

連接 Google 後，瀏覽器會直接向 Google 讀寫整份遊戲庫備份，包含個人分類、標籤、筆記與來源紀錄。頁面開啟且授權有效時，修改後會自動同步；遇到版本衝突會先要求選擇。同步是否完成以網站顯示的狀態為準。

本網站由 GitHub Pages 提供靜態檔案，沒有另設由維護者管理的私人遊戲庫伺服器。你的遊戲庫不會因使用同步功能而自動提交到公開 GitHub 儲存庫。

3.4 資料使用與對外連線

Google 使用者資料只用於上述帳號辨識、備份及同步功能。本應用程式不出售 Google 使用者資料，不將其用於廣告、廣告追蹤或訓練人工智慧模型，也不自動向其他使用者公開你的遊戲庫與筆記。

本應用程式對 Google API 資料的使用遵守 Google API Services User Data Policy，包括 Limited Use 規定。

網站會連接 Google 登入服務、Google Drive 與 Google Fonts；遊戲圖片及來源同步可能連接 Sony、PSNProfiles。整合腳本在你啟動來源同步時讀取相應頁面與公開遊戲名稱資料，並嘗試向 Sony 的 m.np.playstation.com API 取得本帳號的授權日期。Sony 存取權杖只在來源分頁記憶體中使用，不回傳管理頁、不寫入備份。這些服務及 GitHub Pages 可能依各自政策處理 IP 位址、瀏覽器資訊等連線資料。

3.5 保留、移除與你的選擇

  • 可以不連接 Google，使用瀏覽器本機保存及 JSON 匯入、匯出。
  • 「中斷連接」會清除目前頁面記憶體中的授權狀態，停止同步；不會刪除已保存的本機或雲端遊戲庫。
  • 可以在 Google 帳號的第三方連結設定撤銷本應用程式的授權。撤銷存取不會自動刪除既有備份。
  • 若要刪除雲端資料，可至 Google Drive 的「設定 → 管理應用程式」，找到對應的 OAuth 應用程式，從選項刪除隱藏的應用程式資料。刪除前請先中斷本網站的同步，避免重新上傳。
  • 若要刪除本機資料，可在瀏覽器清除此網站的儲存資料，這也會移除該瀏覽器的更新前備份與復原副本。清除本機資料不會自動刪除 Drive 備份。
  • 你下載的 JSON 備份由你自行保管及刪除。共用電腦請特別留意：中斷 Google 連接後，本機遊戲庫仍然存在。

3.6 政策更新與聯絡

資料處理方式調整時，會更新本頁及日期。如有隱私或資料移除問題，請透過 專案問題回報聯絡維護者。該頁為公開討論區，請勿張貼密碼、授權權杖或含私人資料的完整備份。

4. 你的選擇與資料移除

不使用 Google 同步時，可以只瀏覽公開頁面，或在遊戲庫使用本機保存及 JSON 備份。遊戲庫的中斷同步、撤銷授權與刪除 Drive 備份方式，詳見第 3.5 節。

清除瀏覽器對 chiarubi-728.github.io 的網站資料，可能一併移除同一來源下工具的本機資料與復原備份；清除前請先自行匯出重要資料。你下載的檔案由你自行保管及刪除。

5. 政策更新與聯絡

當公開功能或資料用途改變時，會更新本政策與日期，並在相應工具提供必要提示。新增尚未公開的 App 不會僅因出現在首頁，就自動取得其他工具的授權或資料。

首頁、圖鑑或本政策的問題，可透過 首頁問題回報聯絡維護者；遊戲庫問題也可使用 遊戲庫問題回報。這些都是公開討論區，請勿張貼私人備份、密碼、授權權杖或其他個人資料。
