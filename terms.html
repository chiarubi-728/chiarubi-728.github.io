1. 網站與專案用途

Rubi’s Cluttered Corner 由 GitHub 使用者 chiarubi-728 維護，提供卡牌圖鑑、遊戲整理工具及個人 App 專案入口。這是獨立個人專案，並非 Pokémon、Sony、PlayStation、PSNProfiles 或 Google 的官方服務。

本條款涵蓋通用首頁與目前公開的專案入口。各工具的使用方式、資料來源及功能限制，並請參閱其專屬說明。App 卡片目前尚未開放，不提供登入、使用或下載功能。

2. 卡蒂狗・風速狗圖鑑

圖鑑用於瀏覽與核對公開卡牌資料，包含語言、卡號、年份、同圖分組及持續整理中的版本資訊。資料與圖片可能不完整或仍待核對，請以實際卡片及來源資訊進一步確認；圖鑑不構成卡片真偽、價格、完整性或所有權的證明。

卡牌、遊戲名稱與圖片的相關權利屬各自權利人。程式碼與素材的使用條件，請以各專案及來源所列授權為準。

3. PSN Game Catalog 使用說明

以下適用於 PSN Game Catalog；原 遊戲庫服務說明仍可開啟。

工具用途

PSN Game Catalog 由 GitHub 使用者 chiarubi-728 維護，提供個人 PlayStation 數位授權、遊玩及獎盃紀錄整理。此為獨立專案，並非 Sony、PlayStation、PSNProfiles 或 Google 的官方服務。

來源與帳號

請只使用你有權存取及處理的帳號與資料，並遵守來源網站的使用規範。Google 登入為選用功能，用於把遊戲庫備份至你自己的 Drive 應用程式資料空間。

資料判讀

數位授權筆數不等於不同遊戲作品數或付款紀錄；遊玩及獎盃紀錄不能證明你目前仍持有實體片。來源資料、名稱對應及平台合併可能不完整，請以來源網站及你的實際授權為準。

同步與備份

自動同步需要開啟頁面、網路及有效的 Google 授權。關閉前請確認已完成同步；兩台裝置都有修改時，請先比較版本再選擇。重要資料建議定期匯出完整 JSON 備份，避免瀏覽器資料清除、撤銷權限或來源服務變更造成無法取得資料。

聯絡與資料處理

資料如何使用、保存及刪除，請參閱隱私權政策。功能或使用問題可至 GitHub 專案問題回報提出，請勿公開授權權杖或私人備份。

4. 帳號、備份與隱私

請只匯入、同步或處理你有權使用的帳號與資料，並遵守來源服務的使用規範。網站不要求你在本站輸入 Google 或 PlayStation 密碼；登入及授權應在對應服務的頁面進行。

本機存檔與你下載的備份由你自行保管。工具是否已完成保存或同步，以相應工具的實際狀態為準。清除網站資料、結束無痕工作階段或換裝置前，請先匯出重要資料，或確認雲端已成功同步。

資料如何取得、使用、保存及移除，請參閱 隱私權政策。各專案不會僅因共用首頁品牌，就自動共用你的帳號授權或私人資料。

外部連結會前往對應專案或第三方服務；其帳號、資料處理及使用條件，依該服務提供的說明執行。本站不代替來源服務確認你的帳號身分、授權狀態或卡牌與遊戲權利。
